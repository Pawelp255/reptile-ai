# Reptilita App Store Readiness Pack

PASS 6A prepares App Store/TestFlight expansion materials without product feature work.

This folder contains paste-ready drafts and operating checklists for App Store Connect, App Review, screenshot capture, TestFlight QA, known limitations, and release decisioning.

## Files

- `app-store-listing.md` - App name, subtitle, promotional text, descriptions, keywords, category, and age-rating notes.
- `app-review-notes.md` - Reviewer-facing explanation, demo account instructions, privacy/sync notes, and safety disclaimers.
- `privacy-answers-draft.md` - Plain-English App Store privacy questionnaire draft.
- `screenshot-plan.md` - 6.7-inch iPhone screenshot plan with overlay/caption/state/sample-data guidance.
- `testflight-qa-checklist.md` - Final TestFlight QA checklist.
- `known-limitations-and-release-decision.md` - Honest limitations, readiness score, blockers, pre-submission fixes, and post-launch items.

## Validation

No app code was changed for this pass. No build is required unless future edits touch code.
