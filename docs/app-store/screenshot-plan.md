# Screenshot Plan - 6.7-Inch iPhone

Use real or realistic sample data. Keep overlays short, legible, and App Store-safe. Avoid medical diagnosis language, native push notification claims, or promises of automatic cloud backup unless the captured screen clearly supports them.

## Sample Data Baseline

Recommended sample library:

- Orion - Ball Python, Mojave, male, profile photo, feeding due tomorrow, routine check due today.
- Vega - Ball Python, Normal, female, profile photo, cleaning due this week, breeding notes.
- Pip - White's Tree Frog, photo, insect feeding schedule, misting/cleaning notes.
- At least one overdue repeating reminder and one completed task today.
- Several journal entries: feeding, shed, weight, cleaning, health note.
- Optional: one backup/export-ready state in Settings and signed-in sync state if stable.

## Capture QA

- Capture on 6.7-inch iPhone simulator/device.
- Check both status bar and bottom safe area.
- Keep overlays outside critical UI content.
- Use consistent title/caption placement across all screenshots.
- Avoid cropped buttons, modal bottoms, or overscroll gaps.
- Confirm App Store copy and screenshots do not promise push notifications, diagnosis, treatment, or automatic cloud backup beyond implemented sync.
